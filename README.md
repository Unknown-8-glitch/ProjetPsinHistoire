# Le Cauchemar

**Le Cauchemar** est un mini jeu narratif interactif développé en HTML.  
Le joueur se réveille dans un lieu sombre et inconnu, sans aucun souvenir, et doit faire des choix qui influencent la suite de l’histoire.

Chaque page représente une scène du récit et propose plusieurs décisions possibles, créant une expérience immersive basée sur l’exploration, la tension psychologique et la survie.

## Fonctionnalités

- Histoire interactive à choix multiples
- Navigation entre différentes scènes
- Ambiance sombre et mystérieuse
- Projet entièrement réalisé en HTML

## Technologies utilisées

- HTML5
- GitHub Pages pour l’hébergement
